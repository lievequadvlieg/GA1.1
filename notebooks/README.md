MULTIPLY
  multiply function works by typing multiply(a,b) and specifying the values for a and b. it will return the product of the two values.
  for instance: multiply(5,5) returns: 'result=25'

ADD
    This is a function which adds two numbers. To use it, type add(), and in the brackets write the two numbers you would like to add, in the format (a, b). For example; add(5, 4). Please do not enter anything that isn't a number into the brackets.

SUBTRACT
    subtract(a,b) is a function where b is subtracted from a, and a result is defined (not printed). Two variables are required for the function to work.
    EXAMPLE: subtract(10,4) will give 6.
